# Wiki VeciRed Frontend

Contenido para la Wiki de GitHub del repositorio **VeciredFrontend**.

## Cómo activar la Wiki

1. Ve a **GitHub → VeciredFrontend → Settings → Features**
2. Activa **Wikis**
3. Abre **Wiki → Create the first page**
4. Copia el contenido de cada archivo de esta carpeta
